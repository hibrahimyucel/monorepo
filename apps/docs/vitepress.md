
# Vitepress

VitePress is a Vue-powered Markdown static site generator. Every .md file you create inside the workspace automatically compiles into a highly optimized, single-page application (SPA) router layout.

apps/docs/
├── .vitepress/
│   └── config.mts      # The navigation, sidebar, and layout schema definition
├── index.md            # The landing page (Hero layout, features checklist)
├── alignment.md        # Monorepo architecture directory maps & graphs
└── environment.md      # AlmaLinux commands, DNF fixes, and Docker configs
